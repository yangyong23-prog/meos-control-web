## ADDED Requirements

### Requirement: 壳范围配置控制空间设备关系入口
系统 MUST 消费 AMC 壳范围配置中的空间设备关系入口模式，并据此决定空间点击行为和空间详情中的拓扑入口展示方式。

#### Scenario: 配置为从空间详情进入拓扑
- **GIVEN** 壳范围配置将空间设备关系入口设置为“从空间详情打开空间设备关系拓扑图”
- **WHEN** 用户点击一个满足展示范围的空间
- **THEN** 系统先打开空间详情抽屉而不直接打开拓扑页

#### Scenario: 配置为点击空间直接进入拓扑
- **GIVEN** 壳范围配置将空间设备关系入口设置为“点击空间直接打开空间设备关系拓扑图”
- **WHEN** 用户点击一个满足展示范围的空间
- **THEN** 系统直接打开该空间的拓扑页

### Requirement: 环境参数指标配置统一控制页面展示
系统 MUST 统一消费环境参数指标配置，并据此控制 dashboard、全楼模型、楼层地图、空间详情和拓扑中的环境参数、调度状态和控制目标值展示。

#### Scenario: 壳配置不影响实时环境参数字段
- **GIVEN** 某个环境参数字段存在实例化规则
- **WHEN** 页面渲染实时环境参数区域
- **THEN** 系统继续展示该字段的实时值

#### Scenario: 控制型字段未勾选时隐藏
- **GIVEN** 当前环境参数存在控制目标值或调度状态等控制型字段
- **AND** AMC 壳范围配置未勾选对应控制型字段
- **WHEN** 页面渲染对应环境参数区域
- **THEN** 系统不展示对应控制目标值、曲线入口、调度状态标签或筛选项

#### Scenario: 调度状态未勾选时隐藏相关展示
- **GIVEN** 当前环境参数未勾选“调度状态”
- **WHEN** dashboard、全楼模型或楼层地图渲染调度相关统计和筛选条件
- **THEN** 系统不展示对应调度状态统计、标签或筛选项

#### Scenario: 控制目标值未勾选时隐藏详情展示
- **GIVEN** 当前环境参数未勾选控制目标值展示
- **WHEN** 空间详情或拓扑页渲染该环境参数信息
- **THEN** 系统不展示对应控制目标实时值或曲线入口

### Requirement: 空间拓扑中的空间信息遵循环境配置
系统 MUST 在空间拓扑页中展示空间实时环境参数，且壳范围配置仅影响控制目标值与调度状态，不影响实时参数展示。

#### Scenario: 拓扑页展示空间实时环境参数
- **GIVEN** 当前空间存在可展示的实时环境参数
- **WHEN** 用户打开该空间拓扑页
- **THEN** 系统在空间区域展示这些环境参数的实时值
- **AND** 系统不展示曲线和控制目标值

### Requirement: 无末端设备项目隐藏无效控制入口
系统 MUST 在项目维度末端管理设备数量为 0 时隐藏设备列表、批量控制及无效设备筛选入口，同时保留环境品质查看能力。

#### Scenario: 项目无末端设备时隐藏项目级设备入口
- **GIVEN** 当前项目末端管理设备数量为 0
- **WHEN** 页面渲染项目视角或楼层视角控制入口
- **THEN** 系统隐藏设备列表按钮和批量控制 tab

#### Scenario: 项目无末端设备时隐藏地图设备筛选
- **GIVEN** 当前项目末端管理设备数量为 0
- **WHEN** 全楼模型或楼层地图渲染设备筛选和图例
- **THEN** 系统隐藏设备筛选入口和设备状态图例

#### Scenario: 仅环境品质管理项目保留空间结果展示
- **GIVEN** 当前项目仅管理环境品质而不接入设备控制链路
- **WHEN** 用户查看 dashboard、楼层地图或空间详情
- **THEN** 系统继续展示环境品质相关结果
- **AND** 系统不展示依赖末端控制设备的无效入口
