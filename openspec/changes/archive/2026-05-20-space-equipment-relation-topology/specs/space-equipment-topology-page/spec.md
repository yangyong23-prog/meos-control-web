## ADDED Requirements

### Requirement: 单空间拓扑页入口
系统 MUST 支持在单空间上下文中打开空间与设备关系拓扑页，并根据入口来源复用当前空间作为拓扑所属空间。

#### Scenario: 从空间详情打开拓扑
- **GIVEN** 用户已打开某个空间的详情抽屉
- **WHEN** 用户在空间详情的环境品质区域触发“查看空间与设备关系”入口
- **THEN** 系统打开该空间的拓扑页并以当前空间作为拓扑所属空间

#### Scenario: 从空间直接打开拓扑
- **GIVEN** 壳范围配置将空间设备关系入口设置为“点击空间直接打开空间设备关系拓扑图”
- **WHEN** 用户在 dashboard 或楼层地图点击一个满足展示范围的空间
- **THEN** 系统直接打开该空间的拓扑页

### Requirement: 拓扑页与右侧详情并列展示
系统 MUST 允许左侧拓扑区域与右侧详情抽屉并列展示，且两者在 UX 上为并列关系而非 tab 切换关系。

#### Scenario: 拓扑页打开后保留详情抽屉
- **GIVEN** 用户从空间详情进入拓扑页
- **WHEN** 拓扑页成功打开
- **THEN** 右侧详情抽屉保持可见且不因拓扑页打开而被关闭

#### Scenario: 关闭拓扑不影响抽屉
- **GIVEN** 左侧拓扑区域和右侧详情抽屉正在并列展示
- **WHEN** 用户关闭左侧拓扑区域
- **THEN** 右侧详情抽屉继续保持当前详情状态

#### Scenario: 关闭抽屉同步关闭拓扑
- **GIVEN** 左侧拓扑区域和右侧详情抽屉正在并列展示
- **WHEN** 用户关闭右侧详情抽屉
- **THEN** 系统同步关闭左侧拓扑区域

#### Scenario: 拓扑关闭触发器受限
- **GIVEN** 左侧拓扑区域已打开
- **WHEN** 发生任意会导致右侧详情对象切换的业务交互
- **THEN** 系统仅在“用户手动关闭拓扑”或“用户关闭右侧详情抽屉”两类操作下关闭拓扑

### Requirement: 拓扑页保持空间上下文稳定
系统 MUST 在拓扑页生命周期内保持拓扑所属空间不变，除非用户显式重新打开其他空间的拓扑页。

#### Scenario: 拓扑中点击设备后保持空间上下文
- **GIVEN** 拓扑页当前所属空间为某个空间对象
- **WHEN** 用户在拓扑中点击一个设备节点
- **THEN** 系统更新右侧详情为该设备详情
- **AND** 左侧拓扑仍然保持原空间的链路关系不变

#### Scenario: 拓扑打开时从非拓扑入口点击其他设备
- **GIVEN** 拓扑页当前所属空间为某个空间对象，且拓扑处于打开状态
- **WHEN** 用户从地图、设备列表或关联信息区域点击其他设备
- **THEN** 系统更新右侧详情为该设备详情
- **AND** 左侧拓扑保持打开状态
- **AND** 左侧拓扑仍保持原空间的链路关系不变

### Requirement: 拓扑页展示单空间链路关系
系统 MUST 按单空间维度展示空间、空调设备、通风设备及其关系链路，并支持一个上游对应多个下游以及多个上游对应一个下游的关系场景。

#### Scenario: 展示一个上游对应多个下游
- **GIVEN** 后端返回某个上游设备关联多个下游对象的关系结果
- **WHEN** 前端渲染拓扑页
- **THEN** 页面正确展示该上游对象及其多个下游关系连线

#### Scenario: 展示多个上游对应一个下游
- **GIVEN** 后端返回多个上游设备汇聚到同一个下游对象的关系结果
- **WHEN** 前端渲染拓扑页
- **THEN** 页面正确展示多个上游对象与同一下游对象的关系连线

### Requirement: 拓扑页空态与降级展示
系统 MUST 在无可展示设备、无关系链路或关系数据不完整时提供稳定的空态或降级展示，且页面不得报错。

#### Scenario: 空间无可展示设备
- **GIVEN** 当前空间没有满足拓扑展示范围的设备
- **WHEN** 用户尝试打开该空间拓扑页
- **THEN** 系统展示不可查看或空态提示且不报错

#### Scenario: 有设备但无关系链路
- **GIVEN** 当前空间存在可展示设备但后端未返回可视化关系链路
- **WHEN** 用户打开该空间拓扑页
- **THEN** 系统展示设备结果和无链路提示，并保持页面可继续操作
