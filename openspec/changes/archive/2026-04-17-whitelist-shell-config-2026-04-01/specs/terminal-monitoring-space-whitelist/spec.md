## ADDED Requirements

### Requirement: 白名单空间增量追加与去重
系统必须支持通过“按 IOT 监测维度添加空间”和“按楼层地图添加空间”两种方式向白名单增量追加空间，且以空间唯一标识去重。

#### Scenario: IOT 维度多选并集追加
- **GIVEN** 用户在“按 IOT 监测”弹窗勾选多个监测条件
- **WHEN** 用户点击确定
- **THEN** 系统必须将满足任一勾选条件的空间追加到白名单，并完成去重

#### Scenario: 楼层地图选择追加
- **GIVEN** 用户在楼层地图弹窗中选择多个空间
- **WHEN** 用户点击确定
- **THEN** 系统必须将已选空间追加到白名单，并与现有白名单去重合并

### Requirement: 白名单列表管理
系统必须提供白名单列表的单条移除、批量移除、取消选择和按空间名称搜索能力。

#### Scenario: 单条移除白名单空间
- **GIVEN** 白名单列表中存在目标空间
- **WHEN** 用户点击该行“移除”
- **THEN** 系统必须将该空间从白名单中删除

#### Scenario: 批量移除已选空间
- **GIVEN** 用户在白名单列表勾选多个空间
- **WHEN** 用户点击“移除”批量操作
- **THEN** 系统必须删除所有已勾选空间并更新计数

#### Scenario: 取消选择不修改数据
- **GIVEN** 用户已勾选多个白名单空间
- **WHEN** 用户点击“取消选择”
- **THEN** 系统必须仅清空勾选状态，不修改白名单内容

#### Scenario: 按名称搜索筛选
- **GIVEN** 白名单列表存在多条空间记录
- **WHEN** 用户输入空间名称关键字
- **THEN** 系统必须仅显示匹配关键字的白名单空间

### Requirement: 白名单保存与回显
系统必须将白名单空间集合作为配置结果持久化，并在后续进入页面时准确回显。

#### Scenario: 保存白名单配置成功
- **GIVEN** 用户已完成白名单编辑
- **WHEN** 用户点击保存且接口成功
- **THEN** 系统必须持久化当前白名单集合并提示保存成功

#### Scenario: 刷新后回显白名单
- **GIVEN** 白名单配置已成功保存
- **WHEN** 用户刷新或重新进入页面
- **THEN** 系统必须回显最新已保存的白名单空间集合
