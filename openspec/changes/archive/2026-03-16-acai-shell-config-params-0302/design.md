## Context

本变更用于落地 PRD《壳配置（新增空调冷热源参数）-0302迭代》与映射文档《prd-param-group-form-mapping》。

当前问题：
- ACAI 相关分类、参数组、表单类型与状态字段尚未形成统一实现约束。
- 控制逻辑页面尚未完整承接 ACAI 分类与参数持久化。
- 设备组过滤涉及系统类扩展与 Sy2Eg 关系，但前后端责任边界需明确，避免前端重复实现过滤逻辑。

约束条件：
- `prd-param-group-form-mapping.md` 为本次实现依据，映射文档内容不改动。
- `backend_code` 及部分字段命名未最终冻结，前端实现需支持后端字段定稿后的平滑对接。
- 需兼容现有壳配置与控制逻辑页面行为，不引入与 ACAC/ACAH 逻辑冲突。

## Goals / Non-Goals

**Goals:**
- 建立 ACAI 参数的前端分组、表单类型、必填与范围校验实现约束，并覆盖映射表 A 节全部参数。
- 建立二级分类到状态字段组的命名与结构规范，避免跨分类状态复用导致的数据污染。
- 完成控制逻辑页面 ACAI 分类与“冷机与热泵”参数的渲染与持久化契约。
- 固化设备组过滤责任边界：后端过滤、前端消费。
- 形成可执行的任务分解，支撑 `/opsx:apply` 阶段实施。

**Non-Goals:**
- 不在前端实现设备组过滤算法或 Sy2Eg 关系计算。
- 不在本次变更中冻结后端 `backend_code`、最终 payload 字段名。
- 不改造既有 PRD 外的壳配置模块与交互风格。

## Decisions

### 决策 1：以映射表为单一事实源驱动 ACAI 参数渲染
- 方案：以前端 group_key + form_type 映射组织配置项，按二级分类渲染参数面板与校验规则。
- 原因：映射表已覆盖 106 条参数并给出 required/单位/默认值/输入范围，可直接转为可验证实现。
- 备选：按页面硬编码分组与字段。
- 取舍：硬编码短期可快，但可维护性差且难以与 PRD 增量对齐，因此不采用。

### 决策 2：状态模型按“二级分类独立命名空间”治理
- 方案：每个二级分类必须具备完整字段组（`*_tab_on`、`*_tabs_list`、`*_tab_Data`、`*Data`、`*ErrorData`）。
- 原因：避免“安全运行-供冷模式”与“供冷台数计算-供冷模式”等同侧分类复用字段导致覆盖。
- 备选：按冷热模式共享单套状态容器。
- 取舍：共享容器会放大耦合并增加回归风险，不采用。

### 决策 3：控制逻辑 ACAI 参数显隐由后端返回驱动
- 方案：前端仅消费后端返回的可见性与选项数据，保持与已实现“中央空调供冷全系统”一致的交互结果。
- 原因：可与后端真实信息点持久化规则保持一致，降低前端推断错误。
- 备选：前端复刻显隐规则。
- 取舍：规则会随后端演进，前端复刻易漂移，不采用。

### 决策 4：设备组过滤定义为后端职责，前端不新增过滤逻辑
- 方案：前端仅按后端结果渲染 ACCPC/ACOPC/ACOTC/ACCGP/ACCST/ACHPC/ACPPC。
- 原因：过滤依赖系统类集合与关系边（含 Sy2Eg），由后端统一实现可保持口径一致。
- 备选：前端基于返回全集二次过滤。
- 取舍：会造成与后端口径不一致及重复维护，不采用。

## Risks / Trade-offs

- [后端字段未冻结] → 通过映射层与兜底字段适配，减少字段变更对渲染层的影响。
- [参数量大（106 条）导致漏配风险] → 以映射表逐条校验并在任务中设置覆盖率核对步骤。
- [状态字段命名不一致导致数据污染] → 统一命名模板并在代码评审中增加命名校验清单。
- [控制逻辑显隐依赖后端返回] → 提供空数据与异常数据兜底展示，保证页面稳定。

## Migration Plan

1. 先完成 OpenSpec 规格与任务固化，作为实施基线。
2. 在壳配置页面引入 ACAI 二级分类与参数组映射，逐组接入校验规则。
3. 同步接入控制逻辑页面 ACAI 分类与参数持久化字段。
4. 联调后端设备组与显隐接口，验证责任边界。
5. 进行回归验证：分类渲染、参数校验、持久化、历史配置兼容。

回滚策略：
- 保留原有 ACAC/ACAH 流程开关，若 ACAI 接口异常可仅隐藏 ACAI 新增分类，不影响既有系统类配置。

## Open Questions

- ACAI 控制逻辑持久化 payload 的最终字段名与层级结构是否与现有 ACAC/ACAH 完全一致。
- `backend_code` 定稿时间点及是否需要前端兼容多版本字段。
- “主机开启台数限制规则”“是否支持大小机同时开”两类复杂参数的最终接口结构（对象数组字段明细）是否有额外约束。
