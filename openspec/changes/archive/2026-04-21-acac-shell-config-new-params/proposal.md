## Why

当前 ACAC 壳配置中的自动化需求计算条件输入缺少若干关键冷源参数，导致产品设计稿中的参数无法在前端配置、保存与回显，也无法支撑后续边缘端参数推送。该缺口已经进入 0402 迭代范围，需要先补齐规划文档，明确新增参数、动态配置组以及外部推送联动边界。

## What Changes

- 在 ACAC 自动化需求计算条件输入中新增 3 类参数能力：减机前置条件参数、两处供回水温差调整幅度参数、通用工况下的流量需求配置。
- 为“流量需求配置”新增多组动态录入能力，支持基于后端返回候选项选择冷机/换热器范围，并录入三类流量系数。
- 明确实例去重约束、数值校验规则与保存回显边界；对象范围查询和 BDTP 推送均由后端负责。
- 规划前端影响范围为主应用 `src/` 下壳配置相关页面与 API 调用链，不扩散到其它子应用。

## Capabilities

### New Capabilities
- `acac-shell-config-parameter-expansion`: 覆盖 ACAC 壳配置中新增的固定参数项，包括加权平均温度差值 M 与两处供回水温差调整幅度配置。
- `acac-shell-config-flow-demand-config`: 覆盖流量需求配置的动态分组录入、对象实例选择约束、数值校验与保存回显。

### Modified Capabilities
- 无

## Impact

- 影响应用：主应用 `src/`。
- 影响页面：壳配置中 ACAC 自动化需求计算条件输入相关页面与分类渲染逻辑。
- 影响接口：壳配置查询/保存链路。
- 影响数据：新增动态组配置结构、后端返回的设备实例选择结果与系数字段映射。
