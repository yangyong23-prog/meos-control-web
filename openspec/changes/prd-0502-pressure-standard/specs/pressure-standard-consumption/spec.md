## ADDED Requirements

### Requirement: Dashboard 压差分布统计

系统必须在 Dashboard 面板中增加"压差分布"统计环形图。统计所有有压差实例化规则的末端监测空间，空间数为 0 时不展示。压差区间按空间实例获取的上下限计算：过低/正常/过高/无标准。

#### Scenario: 压差分布统计环图展示

- **WHEN** Dashboard 加载时且存在有压差实例化规则的空间
- **THEN** 系统显示压差分布环形图，展示过低/正常/过高/无标准的空间数量

#### Scenario: 压差分布空间数为 0

- **WHEN** Dashboard 加载时且没有有压差实例化规则的空间
- **THEN** 系统不展示压差分布统计模块

#### Scenario: 按空调模板压差启用状态联动

- **WHEN** 空调模板未启用压差
- **THEN** Dashboard 不展示压差相关指标

### Requirement: Dashboard 空间列表压差筛选

Dashboard 空间列表的"环境参数"筛选项必须支持压差选择。选中后展开子筛选项：全部/过低/正常/过高/无数据/无标准/参数屏蔽。空间按压差染色显示。

#### Scenario: 压差筛选项展示

- **WHEN** 用户选择环境参数中的"压差"
- **THEN** 系统展示子筛选项：全部/过低/正常/过高/无数据/无标准/参数屏蔽

#### Scenario: 空间按压差染色

- **WHEN** 用户选择环境参数中的"压差"
- **THEN** 系统按过低/正常/过高/无数据/无标准/参数屏蔽图例对空间进行染色

### Requirement: 模型视角压差分布统计

系统必须在全楼模型和楼层模型的数据统计中增加"压差分布"统计。统计范围分别为所有空间/当前楼层中有压差实例化规则的空间。压差统计右侧不显示调度数量。

#### Scenario: 全楼模型压差统计

- **WHEN** 用户打开全楼模型数据统计
- **THEN** 系统展示压差分布统计，且不显示调度数量

#### Scenario: 楼层模型压差统计

- **WHEN** 用户打开楼层模型数据统计
- **THEN** 系统展示当前楼层压差分布统计，且不显示调度数量

### Requirement: 品质视图空间染色

品质视图的全楼模型与楼层模型的空间染色必须支持压差选项。选中后按过低/正常/过高/无数据/无标准/参数屏蔽图例染色。

#### Scenario: 品质视图压差染色

- **WHEN** 用户在品质视图中选择环境参数为"压差"
- **THEN** 系统按压差图例对空间进行染色

### Requirement: 临时需求配置压差目标设定

临时需求的配置中必须增加"压差目标设定"，非必填，范围 -1000~1000 Pa，最多 1 位小数。预览时扩充压差目标值显示。控制侧查询接口补充：/interventionTaskConfig/list。

#### Scenario: 临时需求新增压差目标

- **WHEN** 用户创建或编辑临时需求
- **THEN** 系统展示压差目标设定输入框（非必填，-1000~1000 Pa，1 位小数）

#### Scenario: 临时需求预览显示压差目标

- **WHEN** 用户预览临时需求
- **THEN** 系统展示压差目标值（若已设定）

### Requirement: 需求目标显示压差标准

需求目标中必须补充显示压差标准信息。

#### Scenario: 需求目标展示压差标准

- **WHEN** 用户查看需求目标
- **THEN** 系统在温度/CO₂/湿度标准基础上展示压差标准信息
