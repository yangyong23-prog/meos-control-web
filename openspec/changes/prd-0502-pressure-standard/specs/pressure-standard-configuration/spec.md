## ADDED Requirements

### Requirement: 环境品质目标新增压差标准配置

系统必须在环境品质目标中新增压差标准的配置页面。包含：全局开关（默认关闭）、压差下限值、压差上限值。开关关闭时清空标准值，且不显示该参数。新增特殊配置时不可控制开关。压差不需要配置调度标准。压差标准不根据空调季设置。

#### Scenario: 压差全局开关默认关闭

- **WHEN** 用户首次进入环境品质目标配置页
- **THEN** 压差全局开关默认为关闭状态，不显示压差上下限输入框

#### Scenario: 打开压差全局开关

- **WHEN** 用户打开压差全局开关
- **THEN** 系统显示压差下限值和上限值输入框

#### Scenario: 关闭压差全局开关

- **WHEN** 关闭压差全局开关
- **THEN** 系统自动清空已有的压差上下限值
- **AND** 查看状态下不显示该参数

#### Scenario: 校验压差上限下限

- **WHEN** 用户录入压差上限和下限
- **THEN** 下限值必须 ≤ 上限值，超过范围提示错误
- **AND** 数值范围 -1000 至 1000 Pa，最多 1 位小数

#### Scenario: 新增特殊配置不可控制压差开关

- **WHEN** 用户新增特殊配置时
- **THEN** 压差的开关跟随全局配置，不可单独修改

### Requirement: 黑名单配置新增压差过滤

系统必须在黑名单的"按 IOT 监测"规则中新增"未交付压差数据的空间"选项。压差取空间信息点 relativePressureDiffToOtherSpace 是否有实例化规则进行过滤。支持多选，提示语需改为"将同时满足勾选条件的空间纳入黑名单"。

#### Scenario: 黑名单配置新增压差选项

- **WHEN** 用户打开黑名单配置
- **THEN** "按 IOT 监测"的选项中新增"未交付压差数据的空间"

#### Scenario: 多选过滤逻辑

- **WHEN** 用户同时勾选温度、CO₂、湿度和压差
- **THEN** 系统将没有任何一项可监测的空间纳入黑名单

#### Scenario: 提示语更新

- **WHEN** 用户打开黑名单配置
- **THEN** 系统显示更新后的提示语："将同时满足勾选条件的空间纳入黑名单..."

### Requirement: 运行标准查看

系统必须在运行标准查看中，当所选日期启用了压差配置时，新增压差标准的显示。

#### Scenario: 运行标准查看展示压差

- **WHEN** 用户查看运行标准，且所选日期使用的模板启用了压差
- **THEN** 系统在温度/CO₂/湿度基础上额外展示压差标准

### Requirement: 国际化翻译

系统必须将本次压差标准配置的所有新增文案纳入国际化翻译体系。

#### Scenario: 压差文案国际化

- **WHEN** 系统渲染压差标准配置页面的文案
- **THEN** 所有用户可见的文本均从 i18n 翻译文件读取
