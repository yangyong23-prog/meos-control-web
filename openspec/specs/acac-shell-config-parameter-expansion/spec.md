# Capability: acac-shell-config-parameter-expansion

## Purpose
定义 ACAC 壳配置中新增固定参数的分组展示、默认值校验、保存与回显能力。

## Requirements

### Requirement: ACAC 壳配置必须支持新增固定参数项
系统必须在 ACAC 自动化需求计算条件输入中新增“加权平均温度差值M”以及两处“供回水温差调整幅度配置”，并按照对应分类稳定展示、保存与回显。

#### Scenario: 展示减机前置条件新增参数
- **WHEN** 用户进入“空调冷源自动需求计算的条件输入”下的“供冷工况”分类并查看“减机前置条件”
- **THEN** 系统必须展示“加权平均温度差值M”参数项

#### Scenario: 展示两处供回水温差调整幅度配置
- **WHEN** 用户分别进入“供回水温差/压差逻辑条件输入”和“泵组供回水温差/压差逻辑条件输入”分类
- **THEN** 系统必须在两处分类中各展示一个“供回水温差调整幅度配置”参数项

### Requirement: 新增固定参数必须满足默认值与输入校验
系统必须对新增固定参数应用 PRD 规定的默认值、必填规则和数值范围限制。

#### Scenario: 加权平均温度差值 M 默认值与校验生效
- **WHEN** 用户首次进入页面或读取空配置
- **THEN** 系统必须为“加权平均温度差值M”回填默认值 `1℃`，并限制输入为一位小数且范围在 `-10` 到 `10` 之间

#### Scenario: 供回水温差调整幅度配置默认值与校验生效
- **WHEN** 用户首次进入页面或读取空配置
- **THEN** 系统必须为两处“供回水温差调整幅度配置”回填默认值 `1℃`，并限制输入为一位小数且范围在 `0` 到 `99` 之间

### Requirement: 新增固定参数必须支持保存后回显
系统必须将新增固定参数纳入现有壳配置保存链路，并在刷新或重新进入页面后准确回显最新已保存值。

#### Scenario: 保存新增固定参数后正确回显
- **WHEN** 用户修改新增固定参数并点击保存，且保存接口成功
- **THEN** 系统必须在页面刷新或重新进入后回显用户最后一次成功保存的值
