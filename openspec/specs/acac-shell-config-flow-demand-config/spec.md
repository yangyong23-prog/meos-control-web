# Capability: acac-shell-config-flow-demand-config

## Purpose
定义 ACAC 壳配置中流量需求配置的动态分组、候选项复用、实例互斥、数值校验、保存回显与边缘端推送约束能力。

## Requirements

### Requirement: ACAC 壳配置必须支持多组流量需求配置
系统必须在“通用工况”下提供“流量需求配置”动态分组录入能力，允许用户新增和维护多组配置。

#### Scenario: 用户新增多组流量需求配置
- **WHEN** 用户在“流量需求配置”区域执行新增操作
- **THEN** 系统必须新增一组可编辑配置，并允许用户继续添加更多配置组

### Requirement: 流量需求配置必须复用后端返回的候选项并限制重复选择
系统必须直接复用壳配置查询结果中返回的对象实例候选项，并禁止同一对象实例在不同配置组中重复选择。

#### Scenario: 直接展示后端返回的对象实例
- **WHEN** 用户打开“选择冷机/换热器范围”选择器
- **THEN** 系统必须直接展示壳配置查询结果中该参数返回的候选项列表，不额外发起关系查询，也不在前端追加类型或监测监控状态过滤

#### Scenario: 已被其它组使用的对象实例置灰
- **WHEN** 某个对象实例已在一组流量需求配置中被选择，且用户在另一组再次打开选择器
- **THEN** 系统必须将该对象实例显示为不可再次选择的置灰状态

### Requirement: 流量需求配置必须校验字段完整性与数值范围
系统必须对每组流量需求配置中的对象范围和 3 个系数字段应用 PRD 规定的必填性与输入校验。

#### Scenario: 对象范围至少选择一个实例
- **WHEN** 用户保存某组流量需求配置且该组未选择任何冷机或换热器实例
- **THEN** 系统必须阻止该组通过校验，并提示至少选择 1 个对象实例

#### Scenario: 三类流量系数字段执行数值校验
- **WHEN** 用户录入“冷冻侧流量系数”“冷却侧流量系数”或“冷却塔散热系数”
- **THEN** 系统必须限制输入为两位小数且范围在 `0` 到 `10` 之间

### Requirement: 流量需求配置必须支持保存回显
系统必须将动态分组配置纳入壳配置保存链路，并在后续进入页面时完整恢复每组配置的实例选择结果和系数字段值。

#### Scenario: 保存后恢复动态分组配置
- **WHEN** 用户保存流量需求配置且保存接口成功
- **THEN** 系统必须在刷新或重新进入页面后恢复已保存的分组数量、每组对象范围及 3 个系数值

### Requirement: 流量需求配置前端保存链路不得追加边缘端推送
系统必须在流量需求配置保存成功后仅执行壳配置成功反馈和回显刷新，不在前端额外调用 BDTP 推送接口。

#### Scenario: 保存成功后仅刷新壳配置数据
- **WHEN** 用户保存流量需求配置且壳配置保存接口成功
- **THEN** 系统必须显示壳配置保存成功反馈，并刷新页面回显数据，不额外发起边缘端推送请求
