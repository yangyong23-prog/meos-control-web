# 四、产品详细设计

## 4.1  环境品质目标

在原本的温度、CO2、湿度的基础上，新增压差标准的配置，压差不配置调度标准

1.  全局配置：由于某些项目是无法监测空间压差数据的，因为此版本在全局配置中加入压差参数是否配置的开关，默认为否，打开开关后才可录入对应的标准，关闭后则不进行录入。关闭后需要清空对应的标准值且在查看状态时不显示该参数；默认关闭可手动打开（规则同现在的湿度配置）
    
2.  新增特殊配置：压差是否可配置由全局配置中的开关进行控制，新增特殊配置时不可以进行开关的控制
    
3.  压差标准：压差指标的录入根据**不根据**项目设置的空调季进行设置，设置的值为：压差下限值、压差上限值；
    
    1.  需要满足：压差下限值≤压差上限值
        
    2.  单位：Pa，可输入的值显示在-1000-1000之间，包含-1000和1000，最多可输入一位小数
        
4.  压差标准的解释说明：
    

*    压差-下限值
    
          空间压差允许的最小值，超出后应立即采取措施提高压差
    
*    压差-上限值
    

       空间压差允许的最大值，超出后应立即采取措施降低压差

5.  外围接口：查询品质标准的接口都需要补充对应的压差标准的查询
    

## 4.2 黑名单配置

黑名单的“按IOT监测”的规则中增加“未交付压差数据的空间”的选择

![Drawing 4](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/WgZOZA8ewYXQ8qLX/img/fe95b748-9ca9-4665-a48d-1548cb8af2c8.png)

1.  “按IOT监测”：温度、CO2和湿度监测的维度来配置。
    
    1.  选择“未交付温度数据的空间”代表没有温度监测的空间需要纳入黑名单。
        
    2.  选择“未交付CO2数据的空间”代表没有CO2监测的空间需要纳入黑名单。
        
    3.  选择“未交付湿度数据的空间”代表没有湿度监测的空间需要纳入黑名单
        
    4.  选择“未交付压差数据的空间”代表没有压差监测的空间需要纳入黑名单
        
2.  可以多选，多个选项都选中，代表某个空间没有任何一个参数可以监测则会被纳入到黑名单，可以参考如下示意图，白色区域的空间将纳入黑名单；页面现有的“勾选后，会将勾选的空间纳入黑名单”的提示语修改为“将同时满足勾选条件的空间纳入黑名单，比如同时勾选“未交付温度数据的空间”和“未交付CO₂数据的空间”，当空间既没法监测温度也没法监测CO₂会被纳入黑名单，任意可监测其中一个时则不会被纳入”
    
    ![Drawing 5](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/WgZOZA8ewYXQ8qLX/img/96d4c0a2-14c5-498d-a2e6-8358ed4865ad.png)
    
3.  信息点说明：
    
    1.  温度取空间的信息点“空气（干球）温度”（信息点编码：tdb）是否有实例化规则进行过滤。
        
    2.  CO2取空间的信息点“空气CO2浓度”（信息点编码：cO2）是否有实例化规则进行过滤。
        
    3.  湿度取空间的信息点“空气相对湿度”（信息点编码：rH）是否有实例化规则进行过滤
        
    4.  压差取空间的信息点“与其它空间的相对压差”（信息点编码：relativePressureDiffToOtherSpace）是否有实例化规则进行过滤
