# 设备拓扑图组件设计方案

## 一、需求概述

### 1.1 核心功能
- 从左往右的层级布局，支持多层级拓扑展示
- 支持一对多、多对一的连接关系
- 支持多箭头汇总合并显示
- 预留环状连接扩展性（箭头弯折到左侧节点）

### 1.2 控制组功能
- 支持"控制组"类型的组合卡片
- 控制组可包含多个子设备（空调机组A、空调机组B等）
- 子设备横排最多2个，超过2个自动换行
- 控制组自身也有状态（基于子设备状态汇总）

### 1.3 设计原则
- 卡片宽高按规则自适应
- 连线居中对齐，基于节点高度/2定位
- 间距28px作为连线处理阈值
- 汇总箭头合并为一个，箭头横线宽度根据连接数量计算

## 四、连线算法设计

### 4.1 连线间距阈值

| 常量 | 值 | 说明 |
|------|-----|------|
| CONNECTION_GAP | 28px | 连线间距阈值，用于判断是否使用折线 |
| MAX_AGGregated_ARROW_WIDTH | 10px | 汇总箭头最大宽度 |
| AGGREGATED_ARROW_BASE_WIDTH | 1.5px | 汇总箭头基础宽度 |

### 4.2 基本连线规则

1. **起点计算**：
   - X坐标：源节点右侧边界 (`source.x + source.width`)
   - Y坐标：源节点高度 / 2（垂直居中）

2. **终点计算**：
   - X坐标：目标节点左侧边界 (`target.x`)
   - Y坐标：目标节点高度 / 2（垂直居中）

3. **路径计算**：
   - 如果水平间距 > 28px：直接直线连接
   - 如果水平间距 ≤ 28px：使用折线（水平段 → 垂直段 → 水平段）

### 4.3 汇总连接处理（多对一）

当多个节点指向同一目标节点时，合并为一条汇总连线：

| 参数 | 值 |
|------|-----|
| 线条颜色 | #409eff (蓝色) |
| 线条宽度 | `min(1.5 × 数量, 10)` px |
| 箭头大小 | 10px |

**宽度计算示例**：
- 2条汇总：2 × 1.5 = 3px
- 5条汇总：5 × 1.5 = 7.5px
- 8条汇总：8 × 1.5 = 12px → 限制为 10px

### 4.4 环状连接处理

当检测到环路时（`target.level <= source.level`），使用虚线弯折连接：

| 参数 | 值 | 说明 |
|------|-----|------|
| 线条颜色 | #e6a23c (橙色) | |
| 线条宽度 | 1.5px | |
| 箭头大小 | 8px | |
| 样式 | 虚线 (strokeDasharray: 5,3) | |
| LOOP_OFFSET_X | 50px | 向左弯折距离 |
| LOOP_OFFSET_Y | 30px | 基础垂直偏移 |

**环状路径算法**：
```
起点 → 水平延伸(50px) → 贝塞尔弯折 → 水平延伸 → 到达目标
```

| 参数 | 值 | 说明 |
|------|-----|------|
| 线条颜色 | #606266 | 灰色 |
| 线条宽度 | 1.5px | |

## 五、布局算法

### 5.1 布局配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| nodeWidth | 120px | 节点默认宽度 |
| nodeHeight | 80px | 节点默认高度 |
| horizontalGap | 100px | 节点间水平间距 |
| verticalGap | 50px | 节点间垂直间距 |
| levelGap | 200px | 层级间距 |

### 5.2 自动布局规则

1. **按层级分组**：根据 `node.level` 将节点分到不同层级
2. **垂直居中**：同一层级的节点按高度居中对齐
3. **位置计算**：
   - X坐标：`level × (levelGap + nodeWidth)`
   - Y坐标：按层级内索引和垂直间距计算，并考虑高度差居中
4. **手动位置优先**：已设置 `position` 的节点保持手动指定位置

### 5.3 防碰撞调整

提供 `adjustLayoutToAvoidOverlap` 函数，用于自动调整节点位置避免重叠：
- 按层级和Y坐标排序
- 逐层检查并调整节点垂直位置
